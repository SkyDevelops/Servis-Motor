# SiMontir

SiMontir adalah sistem reservasi servis motor berbasis web yang membantu pelanggan melakukan reservasi servis, mengelola kendaraan, serta membantu admin dalam mengelola transaksi, reservasi, dan laporan bengkel.

Project ini dibangun menggunakan Express.js, Bootstrap 5, Supabase PostgreSQL, dan Supabase Authentication.


---

# 🚀 Features

- Registrasi dan login pengguna
- Manajemen kendaraan pelanggan
- Reservasi servis motor
- Rekomendasi servis berdasarkan kilometer kendaraan
- Dashboard admin
- Pengelolaan reservasi
- Transaksi kasir
- Invoice / cetak struk
- Laporan keuangan:
  - Harian
  - Bulanan
  - Tahunan
- Cetak laporan keuangan
