Reservasi servis motor berbasis web

SiMontir membuat booking bengkel lebih rapi untuk pelanggan dan admin.

Kelola kendaraan, buat reservasi servis, pantau status, dan gunakan rekomendasi servis berdasarkan kilometer motor.

Cek Rekomendasi Lihat Endpoint

Fitur utama

Alur aplikasi mengikuti kebutuhan reservasi servis motor: akun, kendaraan, jadwal, status, dan dashboard admin.

4Modul API
RBACAdmin & user

Autentikasi

Register, login, logout, dan proteksi API dengan Supabase Auth.

Kendaraan

Tambah, ubah, hapus, dan lihat data motor pelanggan.

Reservasi

Booking tanggal dan jam servis dengan pengecekan slot.

Dashboard Admin

Pantau pelanggan, kendaraan, reservasi, dan update status servis.

Rekomendasi servis otomatis

Masukkan kilometer motor untuk melihat rekomendasi servis dari API SiMontir.

Admin

GET /api/admin/dashboard
GET /api/admin/users
